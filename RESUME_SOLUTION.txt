================================================================================
                          🚀 ÉTAPES MAINTENANT
================================================================================

ÉTAPE 1 : VÉRIFIER OLLAMA (1 min)
  → Cherchez Ollama.exe dans la taskbar Windows
  → Si absent : téléchargez depuis https://ollama.ai/download

ÉTAPE 2 : TÉLÉCHARGER UN MODÈLE (10-30 min)
  → Ouvrez : http://localhost/custom/chatbot/scripts/download-models.php
  → Attendez le message "✨ Configuration Ollama terminée"

ÉTAPE 3 : CONFIGURER LE CHATBOT (2 min)
  → Allez à : http://localhost/custom/chatbot/admin/setup.php
  → Sélectionnez "🖥️ Ollama (Local)"
  → Testez la connexion
  → Sauvegardez

ÉTAPE 4 : TESTER (2 min)
  → Utilisez le chatbot
  → Posez une question
  → Attendez la réponse (10-30 sec au premier appel = normal)

C'EST TOUT ! 🎉

================================================================================
                         🆘 TROUBLESHOOTING
================================================================================

"Ollama non accessible"
  → Lancez ollama.exe
  → Attendez 5 sec

"Modèle non disponible"
  → Relancez download-models.php
  → Attendez fin téléchargement

"Réponse lente (30+ sec)"
  → Normal au 1er appel !
  → Les suivantes seront rapides

"PC très lent"
  → Utilisez "neural-chat"
  → Ou réduisez tokens max

"Chatbot ne répond pas"
  → Vérifiez Ollama tourne
  → Testez connexion dans setup.php

→ Documentation complète dans INSTALLATION_OLLAMA.md
