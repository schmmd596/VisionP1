================================================================================
  📋 ÉTAPES À SUIVRE MAINTENANT
================================================================================

1️⃣  VÉRIFIER QU'OLLAMA TOURNE
    ➜ Cherchez "Ollama" dans la taskbar Windows (coin bas-droit)
    ➜ Si absent : téléchargez depuis https://ollama.ai/download et lancez

2️⃣  TÉLÉCHARGER UN MODÈLE (5-30 minutes)
    ➜ Ouvrez dans votre navigateur :
       http://localhost/custom/chatbot/scripts/download-models.php
    ➜ Attendez le message "✨ Configuration Ollama terminée"
    ➜ C'est normal que ce prenne 10-30 min (dépend de votre connexion)

3️⃣  CONFIGURER LE CHATBOT (2 minutes)
    ➜ Allez à : http://localhost/custom/chatbot/admin/setup.php
    ➜ Sélectionnez "🖥️ Ollama (Local - Auto-hébergé)"
    ➜ Cliquez "Tester la connexion" → doit afficher ✅
    ➜ Cliquez "Sauvegarder la configuration"

4️⃣  TESTER LE CHATBOT
    ➜ Utilisez le chatbot normalement
    ➜ Première réponse prendra 10-30 sec (normal, charge le modèle)
    ➜ Les réponses suivantes seront rapides (2-5 sec)

C'est fini ! Votre chatbot utilise maintenant Ollama ! 🎉

================================================================================
  🆘 SI QUELQUE CHOSE ÉCHOUE
================================================================================

"Ollama n'est pas accessible"
  → Lancez ollama.exe (cherchez dans la taskbar)
  → Attendez 5 sec et réessayez

"Modèle non disponible / téléchargement échoué"
  → Relancez : http://localhost/custom/chatbot/scripts/download-models.php
  → Vérifiez vous avez assez de place disque
  → Attendez la fin du téléchargement (10-30 min)

"Réponse très lente (30+ secondes)"
  → C'est normal au PREMIER appel (charge le modèle en RAM)
  → Les appels suivants seront rapides
  → Si toujours lent : vérifiez ressources CPU/RAM

"PC très ralenti"
  → Utilisez "neural-chat" au lieu de "mistral" (moins lourd)
  → Ou réduisez "Tokens maximum" à 1024
  → Fermez autres applications

"Erreur 'Non authentifié'"
  → Reconnectez-vous à votre compte utilisateur
  → Le chatbot nécessite une session active

→ Pour plus d'aide, consultez INSTALLATION_OLLAMA.md (troubleshooting complet)
